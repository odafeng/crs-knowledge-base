Bottom Line

STELLAR-303 是史上首個在 MSS / 非 dMMR mCRC 後線治療中達到總生存（OS）顯著改善的免疫治療 Phase 3 試驗，證實 zanzalintinib（多靶點 TKI）+ atezolizumab 優於 regorafenib（OS HR 0.80, p=0.0045），打破了「MSS mCRC 對免疫治療無效」的長期觀念。然而絕對生存獲益僅約 1.5 個月，且毒性更高（Grade 3+ TRAE 60% vs 37%），臨床上仍需以 biomarker 導向謹慎評估。

STELLAR-303 Trial Summary

STELLAR-303 是一項針對先前治療過的 microsatellite-stable (MSS) / 非 dMMR 轉移性大腸直腸癌（mCRC）後線（3L+）族群的 Phase 3 隨機對照試驗，比較 zanzalintinib 合併 atezolizumab 與標準照護 regorafenib。一手數據發表於 Lancet 2025（PMID 41130252）。

Editorial Commentary

Bando 與 Yoshino 在這篇 editorial 中強調，STELLAR-303 的結果具有范式轉移（paradigm shift）意義：這是免疫治療首次在「免疫冷腫瘤」MSS mCRC 後線設定中達到 OS 主要終點的陽性 Phase 3 試驗。其機轉假說在於 zanzalintinib 作為多靶點 TKI（涵蓋 VEGFR、MET、AXL、TAM 家族）可重塑腫瘤微環境，將「冷腫瘤」轉為對 checkpoint 抑制有反應的「熱腫瘤」，進而與 atezolizumab 產生協同作用。

作者同時提出臨床上的重要保留：（1）絕對中位 OS 獲益僅約 1.5 個月，臨床意義有限；（2）Grade 3+ 治療相關不良事件高達 60%（vs regorafenib 37%），毒性負擔顯著較高；（3）無肝轉移亞族（HR 0.79）在中期分析未達統計顯著性，提示獲益族群可能存在異質性。據此，作者主張未來應發展 biomarker 導向（biomarker-guided）的病人篩選策略，以辨識最可能獲益、且能耐受毒性的族群。
