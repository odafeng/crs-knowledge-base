Zanzalintinib plus atezolizumab versus regorafenib in refractory metastatic colorectal cancer (STELLAR-303)

Authors: Hecht JR, et al.
Journal: Lancet 2025
DOI: 10.1016/S0140-6736(25)02025-2
PMID: 41130252
Study: STELLAR-303 — Phase 3 randomized controlled trial (n=901, MSS/pMMR refractory mCRC)
Bottom Line: STELLAR-303 是後線 mCRC 治療的歷史性突破：全球首個在 MSS/pMMR（非 MSI-H）mCRC 族群中，以免疫治療為基礎的 Phase 3 試驗達到 OS 主要終點。Zanzalintinib + atezolizumab 頭對頭擊敗現行標準 regorafenib（OS HR 0.80，p=0.0045），成為首個在 MSS mCRC 達到 Phase 3 OS 終點的免疫治療組合。

Abstract

Design: STELLAR-303 為一項全球性、開放標籤、隨機分配的 Phase 3 試驗（n=901），於 MSS/pMMR（非 MSI-H）難治型轉移性大腸直腸癌（mCRC）族群中，比較多靶點 TKI 與 PD-L1 抑制劑組合相對於現行標準後線單藥治療的療效。這是首個在 MSS/pMMR mCRC 族群中以免疫治療為基礎並達到 OS 主要終點的 Phase 3 試驗。

Arms:

  • Experimental: Zanzalintinib（靶向 VEGFR / MET / TAM 激酶的多靶點 TKI）+ atezolizumab（PD-L1 抑制劑）
  • Control: Regorafenib（現行後線標準口服多激酶抑制劑）

Endpoints: Dual primary：整體存活期（OS）於 ITT 族群，以及 OS 於無肝轉移（no liver metastases）亞族群。

Key Results

Endpoint Zanzalintinib + Atezolizumab Regorafenib Effect size
mOS（ITT，主要終點） 10.9 mo 9.4 mo HR 0.80（95% CI 0.69–0.93），p=0.0045
OS（無肝轉移亞族群，共同主要終點） 尚未達標（interim） HR 0.79，p=0.087
Grade ≥3 TRAEs 60% 37% 實驗組毒性較高

這是第一個直接頭對頭擊敗 regorafenib 的 Phase 3 試驗。主要侷限為毒性較高（Grade ≥3 治療相關不良事件 60% vs 37%），且無肝轉移亞族群的第二共同主要終點尚未達到統計顯著（HR 0.79，p=0.087，仍在追蹤中）。

Conclusions

STELLAR-303 在 MSS/pMMR mCRC 族群具有典範轉移的意義：它是全球首個在非 MSI-H 族群中以免疫治療為基礎、並於 Phase 3 達到 OS 主要終點的試驗，且直接頭對頭擊敗 regorafenib。Bando & Yoshino（Med, 2026）評論稱此結果「可能重塑治療典範並重燃 MSS 疾病生物標記引導免疫治療的興趣」。

臨床應用時需權衡較高的毒性，並留意無肝轉移亞族群共同主要終點的後續追蹤結果。整體而言，本試驗為 MSS mCRC 後線免疫治療開啟新的方向。
