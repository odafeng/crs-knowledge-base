STELLAR-303: Breaking the immunotherapy wall in MSS colorectal cancer

Authors: Bando H, Yoshino T
Journal: Med 2026
DOI: 10.1016/j.medj.2025.100957
PMID: 41519113
Type: Editorial / Commentary（針對 STELLAR-303 Phase 3 試驗）
Bottom Line: STELLAR-303 首次在 MSS mCRC 達成 Phase 3 免疫療法 OS 獲益，zanzalintinib + atezolizumab 有望取代 regorafenib 成為後線新標準（尤其無肝轉移族群）。

背景

MSS（microsatellite stable）約佔 mCRC 的 85–90%，過去數十個免疫檢查點抑制劑（ICI）試驗在 MSS mCRC 均告失敗，形成所謂的「免疫療法壁壘」。STELLAR-303 是首個在此族群達成 Phase 3 成功的免疫療法組合試驗。

試驗設計（STELLAR-303）

項目內容
族群非肝轉移 MSS mCRC（後線）
試驗組Zanzalintinib（XL092；靶向 VEGFR / MET / TAM 激酶）+ Atezolizumab
對照組Regorafenib
主要終點Overall Survival（OS）

關鍵結果

在非肝轉移 MSS mCRC 族群中，zanzalintinib + atezolizumab 相較 regorafenib 達到顯著的 OS 獲益，為 MSS 族群中首個 Phase 3 成功的免疫療法組合。療效集中於無肝轉移族群，提示腫瘤微環境差異可能是重要的 biomarker。具體 HR / mOS 數值待原始試驗報告。

可能機制

核心機制可能在於 zanzalintinib 的 MET / TAM 抑制帶來免疫微環境重塑（immune microenvironment remodeling），使原本對 ICI 無反應的 MSS 腫瘤恢復免疫敏感性。療效集中在無肝轉移族群，呼應肝轉移相關的免疫抑制微環境理論。

臨床意義（Editorial 觀點）

本文為 Bando H 與 Yoshino T 所撰的權威性 Editorial。雖為評論而非原始數據，但作者權威性極高，清晰指出 biomarker 導向的 MSS 免疫療法研究新方向。相較同批 sintilimab + fruquintinib 的 Phase 2 探索性研究，STELLAR-303 的 Phase 3 成功在證據等級上具決定性差距，對後線治療格局影響重大。

zanzalintinib + atezolizumab 有望取代 regorafenib 成為無肝轉移 MSS mCRC 的後線新標準，並開啟 biomarker 導向（如肝轉移狀態、腫瘤微環境）的 MSS 免疫療法研究方向。
